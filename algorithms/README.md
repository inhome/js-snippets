# 小算法

运行：`node --test algorithms/test.js`（仓库根目录，Node.js 18+）。

| 练习 | 要点 | 时间复杂度 |
| --- | --- | --- |
| 二分查找 | 用左闭右开区间，重复值返回第一个位置 | O(log n) |
| 归并排序 | 相等时先取左边，保留稳定性；不修改输入 | O(n log n) |
| BFS 最短路径 | 入队就标记，用父节点还原路径；仅适用于无权图 | O(V + E) |
| 括号匹配 | 栈顶必须和右括号配对，最后栈要清空 | O(n) |
| 无重复字符子串 | 滑动窗口左边界只能向前走 | O(n) |

二分查找假定输入已经按数字升序排列，不额外遍历检查。字符串按 Unicode
码点计算，组合重音和家庭 emoji 不一定算一个字符。括号匹配也不处理字符串
字面量或注释，不是语法解析器。

容易漏的边界：空输入、重复值、找不到目标、有环的图，以及 `abba` 中第二个
`a` 不能把窗口左端拉回去。测试里把这些情况单独列出来。
